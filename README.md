# PragyaPortfolio

An ASP.NET CORE MVC portfolio application built to showcase my technical skills, projects and learning journey

---

## About

PragyaPortfolio is a personal portfolio website developed using ASP.NET Core MVC. This project is being built incrementaly while learning C#, Entity Framework Core, SQLite,Git and GitHub.

In addition to application development, this repository is used to practice professional GitHub workflows including branches, issues, pull requests, project boards, and documentation.

---

## Project Goals

- Build a professional portfolio website
- Learn ASP.NET Core MVC development
- Implement SQLite using Entity Framework Core
- Practice Git and GitHub workflows
- Maintain project documentation using Markdown
- Prepare for the GitHub Foundations certification
